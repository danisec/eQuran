#
#   NVIDIA (CUDA 12):   pip install onnxruntime-gpu
#   AMD (ROCm):         pip install onnxruntime-rocm
#   Windows (any GPU):  pip install onnxruntime-directml
#   Apple Silicon:      onnxruntime already ships CoreML
#   Intel (OpenVINO):   pip install onnxruntime-openvino
